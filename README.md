## How I work with AI

- Start from the real workflow, not the model
- Design AI agents with clear responsibilities, sensible boundaries, and human judgment kept in the loop
- Use MCP, agents and vibe coding to turn ideas into working prototypes fast
- Humans stay the reviewer — AI prepares, people decide

Let people focus on judgment, let systems handle execution, and let every result become the starting point for the next iteration.
