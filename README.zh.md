## 我如何用 AI 做事

- 从真实的工作流程出发，而不是从模型出发
- 设计职责清晰、有边界、始终保留人工判断的 AI Agent
- 用 MCP、Agent 和 Vibe Coding 快速把想法变成可用的原型
- 人始终是审核者——AI 负责准备，人负责决定

让人专注于判断，让系统专注于执行，让每一次结果成为下一次进化的起点。
